# Security Policy

## Reporting a Vulnerability

If you find a security issue with the app, please [report it to me](https://http-shortcuts.rmy.ch/contact) and provide as many details as possible. I will try to respond to these reports within a few days.

Please note though that this app is mainly intended for powerusers who know what they are doing, and much of how secure it is depends on how they use it. As such, there are certain ways in which the app can be used in a less-than-optimal way, in order to facilitate specific use cases. However, all of these features should have an indication about their risks, either in the app or in the documentation, to allow users to make an informed decision on whether they want to use them.
