在您的主畫面放置捷徑 (小工具)，以便提交 HTTP 請求至種種您喜愛的 REST 形式 API、網路服務與其他 URL 資源。家居自動化專案的必備之選！
<ul><li>HTTP 與 HTTPS</li><li>GET、POST、PUT、DELETE、PATCH、HEAD、OPTIONS 和 TRACE</li><li>基本驗證、摘要式驗證、持有人驗證以及用戶端憑證驗證</li><li>自訂請求標頭</li><li>自訂請求內文 (僅限文字)</li><li>作為表單資料或請求內文上載檔案</li><li>支援 HTTP 代理伺服器</li><li>支援自我簽署的憑證</li><li>內建圖示、支援自訂圖示或使用網站的最愛圖示</li><li>以快顯訊息、視窗或對話方塊顯示回應，亦可安靜執行</li><li>藉索引標籤組成類別群組</li><li>藉變數導入數值 (例如文字、數字、密碼、選取、色彩、日期 …)</li><li>於執行之前或後執行任意 JavaScript (包括特殊動作)，例如 (但不限於)：<ul><li>顯示對話方塊</li><li>顯示快顯訊息</li><li>提示使用者輸入 (例如詢問日期、密碼、文字 ...)</li><li>剖析 JSON 或 XML 回應</li><li>運算 HMAC</li><li>儲存數值到全域變數容後使用</li><li>震動</li><li>播放通知音效</li><li>傳送 TCP 或 UDP 封包</li><li>傳送 MQTT 訊息至訊息代理</li><li>wake-on-lan</li><li>傳送 Android 意圖</li><li>觸發 Tasker 工作</li><li>讀取二維碼 (經第三方應用程式)</li><li>讀取目前的實體位置</li></ul></li><li>以 JSON 或 cURL 格式匯入與匯出</li><li>第三方整合 (例如 Tasker)</li><li>深色模式支援</li></ul>
且拋磚引玉一些妙用 HTTP 捷徑的好主意：<ul><li>執行在您的網頁伺服器上的指令碼</li><li>控制您的家居自動化系統以及 IoT 裝置</li><li>與您的 RaspberryPi 以及 Arduino 妙想專案互動</li><li>自動化工作流程</li></ul>
