הצב קיצורי דרך (ווידג'טים) במסך הבית שלך כדי לשלוח בקשות HTTP לכל ממשקי ה-API המועדפים עליך, שירותי רשת ומשאבי URL אחרים. מצוין לפרויקטים של אוטומציה ביתית!
 * HTTP ו-HTTPS
 * GET, POST, PUT, DELETE, PATCH, HEAD, OPTIONS ו-TRACE
 * אימות בסיסי, אימות Digest, אימות Bearer ואימות באמצעות אישור לקוח
 * כותרי בקשה מותאמים אישית
 * גוף בקשה מותאם אישית (טקסט בלבד)
 * העלאת קבצים כנתוני טופס או גוף בקשה
 * תמיכה בשרתי פרוקסי HTTP ו-SOCKS
 * תמיכה באישורים בחתימה עצמית
 * אייקונים מובנים, תמיכה באייקונים מותאמים אישית או שימוש בפאביקון של אתר
 * הצגת תגובה כהודעה קופצת, חלון או דיאלוג, או הפעלה שקטה
 * קיבוץ לקטגוריות באמצעות לשוניות
 * הזרקת ערכים באמצעות משתנים (לדוגמה: טקסט, מספרים, סיסמאות, בחירות, צבעים, תאריכים, ...)
 * הפעלת JavaScript שרירותי לפני ואחרי הביצוע, כולל פעולות מיוחדות, כגון (אך לא רק):
   * הצגת דיאלוגים
   * הצגת הודעות קופצות
   * בקשת קלט מהמשתמש (לדוגמה: בקשה לתאריכים, סיסמאות, טקסט, ...)
   * ניתוח תגובות JSON או XML
   * חישוב HMAC
   * אחסון ערכים במשתנים גלובליים לשימוש מאוחר יותר
   * רטט
   * השמעת צלילי התראה
   * שליחת חבילות TCP או UDP
   * שליחת הודעות MQTT לברוקר
   * Wake-on-LAN
   * שליחת Android intents
   * הפעלת משימות Tasker
   * קריאת קוד QR (באמצעות אפליקציה צד שלישי)
   * קריאת מיקום פיזי נוכחי
 * ייבוא וייצוא בפורמט JSON או cURL
 * אינטגרציה עם צד שלישי (לדוגמה: Tasker)
 * תמיכה במצב כהה
כמה רעיונות למה להשתמש בקיצורי דרך HTTP:
 * הפעלת סקריפט בשרת האינטרנט שלך
 * שליטה במערכת האוטומציה הביתית ובמכשירי ה-IoT שלך
 * אינטראקציה עם פרויקטי ה-RaspberryPi ו-Arduino שלך
 * אוטומציה של תהליכי עבודה
 * הורדת קבצים
