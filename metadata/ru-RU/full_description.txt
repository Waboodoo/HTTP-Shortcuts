Разместите ярлыки (виджеты) на домашнем экране, чтобы отправлять HTTP запросы на все ваши любимые RESTful API, веб-сервисы и другие URL-ресурсы. Отлично подходит для проектов автоматизации дома!
<ul><li>HTTP и HTTPS</li><li>GET, POST, PUT, DELETE, PATCH, HEAD, OPTIONS и TRACE</li><li>Базовая аутентификация, Digest Authentication, Аутентификация предъявителя и Клиента</li><li>Пользовательские заголовки запроса</li><li>Пользовательское тело запроса (только текст)</li><li>Загрузка файлов как форм данных или тела запроса</li><li>Поддержка HTTP и SOCKS прокси</li><li>Поддержка самоподписанных сертификатов</li><li>Встроенные значки, поддержка пользовательских иконок или использование значка сайта</li><li>отображение ответа как всплывающего окна, окна или диалога, или запустить без звука</li><li>Группировка по категориям через вкладки</li><li>Включение значения через переменные (e. ., текст, цифры, пароли, выборки, цвета, даты, …)</li><li>Запуск произвольного JavaScript до и после выполнения, включая специальные действия, Например, (но не ограничиваясь этим):<ul><li>show dialogs</li><li>show toasts</li><li>prompt for user input (e.g. запрос даты, пароли, текст, ...</li><li>анализ JSON или XML ответов</li><li>вычисление HMAC</li><li>значения магазина в глобальные переменные для последующего использования</li><li>вибрация</li><li>отправка сообщений о воспроизведении оповещений</li><li>отправка TCP или UDP пакетов</li><li>отправка MQTT сообщений брокеру</li><li>wake-on-lan</li><li>отправка Android намерений</li><li>выполнение задач Tasker</li><li>чтение QR-кода (через стороннее приложение)</li><li>чтение текущего местоположения</li></ul></li><li>Импорт и экспорт в JSON или cURL формата</li><li>интеграция сторонних организаций (e. . Tasker)</li><li>Поддержка темного режима</li></ul>
Некоторые идеи использования ярлыков HTTP:<ul><li>Выполнить скрипт на вашем веб-сервере</li><li>Управление вашей системой домашней автоматизации и IoT устройствами</li><li>Взаимодействие с проектами RaspberryPi и Arduino tinkering</li><li>Автоматизация рабочих процессов</li><li>Скачать файлы</li></ul>
